# Game engines

Every level's games are JSON files (`app/assets/content/games/<world>/*.json`, schema:
`app/assets/content/schema.json`). The `game` field names one of these engines and `params` configures it.
A new level that uses an existing engine needs **no Dart changes**. Params that change with difficulty go in
`difficulty.steps` (merged over `params`).

Shared rules, handled by `RoundController` for every engine:

- `rounds` (default 5): each round is recorded with `MasteryTracker.record(skill, correct, hintsUsed)`
  for every skill in `skills`; "correct" means solved with no wrong attempt.
- Adaptive difficulty: `difficulty.raiseAfter` first-try rounds in a row → next step;
  `difficulty.lowerAfter` wrong attempts in a row → previous step and a hint.
- Hints: after 1 wrong attempt on step 1, after 2 on step 2, never from step 3 (override with `hintAfter`;
  `0` = never).
- Feedback: tap sound on touch-down, "correct" chime + happy Pip, curious Pip on a mistake (never sad),
  < 2 s celebration at the end.

`items` everywhere accepts vocab ids (`"cow"`), one tag (`"tag:farm"`) or several (`"tags:animal+farm"`).
Vocab lives in `app/assets/content/vocab/*.json`, generated by `app/tool/vocab_table.py`.

| Engine | What the child does | Params |
| --- | --- | --- |
| `sound_match` | Hears a prompt, taps the matching card (2–6) | `mode`: `name` · `sound` · `colour` · `shape` · `number` · `letter` · `starts_with` · `more` · `fewer` · `bond` · `sum` · `take_away`; `choices`; `items`; `numbers` `[min,max]`; `show` (`numeral`·`dots`·`group`); `letters`; `total` (5/10) |
| `drag_to_target` | Drags one item onto the right zone | `mode`: `food` · `habitat` · `baby` · `shape_hole`; `items`; `targets` (2–4) |
| `tap_count` | Taps each object once while Pip counts | `numbers` `[min,max]` (≤ 20); `items` |
| `trace_path` | Traces a letter, digit or shape | `glyphs`: letters (incl. `ë`, `ç`, digraphs as one tile), `0`–`9`, `circle` `square` `rectangle` `triangle` `diamond` `star` `heart`; one per round |
| `pairs_memory` | Memory pairs, 2×2 to 4×4 | `pairs` (2–8); `pairing`: `picture` · `picture_sound` · `letter_picture` · `numeral_dots`; `items`; `letters`; `numbers`; `players` (1/2) |
| `sequence_pattern` | Chooses what comes next | `items`; `patterns` (`AB` `AAB` `ABB` `ABC` `AABB`); `length`; `choices` (2–3) |
| `sort_bins` | Drags several items into 2–3 bins | `by`: `size` · `lives` · `colour` · `first_letter` · `tag`; `bins`: `[{"value", "item"?, "say"?}]`; `items`; `perRound` |
| `blend_tiles` | Drags letter-sound tiles into a word | `words`: vocab ids, or `{"en": [...], "sq": [...]}` |

Letters and first-letter checks are per language: Albanian uses its 36-letter alphabet, with the digraphs
dh, gj, ll, nj, rr, sh, th, xh, zh treated as single letters (`graphemes()` in `lib/games/common/pools.dart`).

Each engine lives in `app/lib/games/<name>/`; tests and goldens in `app/test/games/<name>/` and
`app/test/goldens/games/`.
